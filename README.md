## 에이전트 운용 체계

- **Claude Code** — 오케스트레이터. 리서치, 기획, 작업 분배, 코드 리뷰, 통합을 담당.
- **Codex CLI** — 하위 코딩 에이전트. Claude가 `codex exec`로 구현 작업을 위임.

자세한 운용 규칙은 `CLAUDE.md` 참조.
