# 합성 데이터 카탈로그

이 경로의 모든 데이터는 RWA Guard 데모와 테스트를 위해 직접 생성한 합성 데이터다. 실제 부동산, 발행사, 투자자, 거래 또는 개인정보를 나타내지 않는다.

| 경로 | 용도 |
|---|---|
| `assets/han-river-office-01.json` | 합성 자산 기본정보 |
| `documents/issuance-terms-01.txt` | 문서 AI·근거 span 입력 |
| `replay/oracle-shock-01.json` | P0 온체인 Replay 경로 |
| `valuation/comparables-01.csv` | P1 기준가 모델 개발용 합성 비교값 |

외부 데이터로 교체하거나 보강할 때는 출처, 라이선스, 취득일, 변환과정을 이 문서에 기록한다.
