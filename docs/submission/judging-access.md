# 심사 접근 안내

공개 데모에서 심사위원이 기능을 온전히 확인하기 위한 접근 정보다.

## 접근 범위

| 동작 | 접근 코드 | 대상 화면 |
| --- | --- | --- |
| 읽기 | 불필요 | 관제 홈, 자산 상세, 발행조건 검토, 검증 결과, 증거 리포트 |
| 변경 | 필요 | 자산 등록, 문서 업로드, 통제조건 확정, 컨트랙트 검사 |

읽기는 잠금 없이 모두 열린다. 변경 작업만 검토자 세션을 요구한다.

## 잠금 해제

1. 화면 우측 상단 `검토자 잠금 해제`
2. 아래 코드 입력

```
RwaGuard-Judge-2026!
```

세션은 30분간 유지되며 5회 실패하면 15분간 잠긴다.

## 체험 순서

1. `샘플 검증 시작` — 저장된 데모 리포트를 재현한다.
2. `신규 자산 등록` — 2단계에서 시나리오를 고른다.
   - `샘플 A · 확정 위험 발생` → 통제 공백 4건, Exploit Risk 100 CRITICAL
   - `샘플 B · 깨끗한 결과` → 결함 0건, Exploit Risk 0 LOW
   두 시나리오는 **같은 발행조건서**를 쓴다. 결과를 가르는 것은 컨트랙트다.
3. 문서 검토에서 P0 통제조건 6개를 확정한 뒤 컨트랙트 검사를 실행한다.
4. 검증 결과와 증거 리포트에서 문서 page/span과 코드 file/line 연결을 확인한다.

## 이 코드의 성격

심사 기간 공개를 전제로 정한 값이다. 운영 secret이 아니며 다음을 지킨다.

- `OPERATOR_TOKEN`, `OPERATOR_SESSION_SECRET`, `POSTGRES_PASSWORD`는 저장소에 두지 않는다.
- 심사 종료 후에는 이 코드를 폐기하고 다른 값으로 교체한다.
- 이 값을 운영 환경에 재사용하지 않는다.

## 배포 주입

`OPERATOR_ACCESS_CODE`를 **백엔드와 웹 양쪽에 같은 값**으로 주입한다. 한쪽만
설정하면 검증이 실패한다. 코드 요건은 20자 이상이며 대문자, 소문자, 숫자,
기호를 각각 포함해야 한다.
