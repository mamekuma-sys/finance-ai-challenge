| 사인 | 내용 |

근거: `docs/research/13-concept-brief.md` 사망표 · `20-concept-comparison.md` ·
`docs/decisions.md` 2026-07-26 항목.

## 그럼에도 보존하는 이유

1. **기존 서비스 조사 기록** — 루브릭 R5의 감점 트리거(기존 서비스 4개 층 미조사, −5)를
   방어하는 근거의 일부다. "무엇을 조사해서 무엇을 죽였는가"가 독창성 논증이다
2. **개정 루프 방법론** — 휴먼 패널 5라운드 → 개정 계약(D/E/F/G) → judge 재채점 →
   재검증. P단계 92.8을 만든 절차이며 「기록으로」에도 그대로 적용한다
3. **표절·중복 방어** — 폐기 이력이 남아 있어야 이후 산출물의 독립성을 설명할 수 있다
