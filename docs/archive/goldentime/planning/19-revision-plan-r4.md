# 개정 라운드 4 — M0 동결 마감 패치 (18-m0-freeze-verification 반영)

작성: 2026-07-25. 패널 4라운드 결함 V4-01~V4-07을 닫는 확정 결정 G1~G7.
`10`·`11`의 0.5-r4 개정은 이 계약을 따른다. 조건 3(MCP·토큰)·4(코어 재동결)는 충족
판정이므로 다시 열지 않는다.

## G1. 전역 후속 승격 규칙 (V4-01)

§4.5.1 ④를 **승격**으로 확정한다: R3가 이미 수집한 `procedure:written_followup` 행이
병합 결과에 있으면 **그 카드를 전역 필수 카드로 승격**한다(새 카드를 생성하지 않음 —
중복 금지). 해당 행이 없을 때만 카드를 생성한다. 어느 경로든 결과는 단일 카드다.

## G2. 노출 슬롯 예약·축출 순서와 순위 직렬화 (V4-02)

- 각 카드의 정렬 키 = (강제 노출 여부, severity — 질문 카드는 잠재 severity, 규칙 내
  순번). **강제 노출 카드**: 전역 서면 후속(항상), proxy 안내(항상 마지막).
- 노출 4개 = 강제 노출 카드가 먼저 슬롯을 예약하고, 남은 슬롯을 정렬 상위 일반 카드가
  채운다. 초과 일반 카드는 **낮은 severity부터** `next_steps`로 내린다.
- `ActionCard.priority` 타입을 `number`로 변경: 노출 카드 1~4, `next_steps`는 5부터
  **전체 순위 연속 번호**(직렬화 단일화).

## G3. 우선순위 문구 단일화 + 무확인 기본값 (V4-03)

- §4.5.1 ②에 추가: 확인된 severity 1~6 행이 없으면 비교 기준을 rank 7로 두어 질문
  카드를 1번으로 삽입한다.
- §4.4의 "최우선 삽입", §4.5.3의 "1번 카드가 된다" 잔존 문구를 "§4.5.1 ②의 위치 규칙을
  따른다"로 교체하고, **충돌 시 §4.5.1이 우선**한다는 문장을 §4.5 서두에 명시한다.

## G4. 스냅샷 기본값 정정 (V4-04)

§4.5.4 전제: 미지정 축 기본값은 `transfer_state=not_sent`, 노출 축 `none`,
`safe_device_available=yes`, `user_role=self`. 스냅샷 e에 `transfer=not_sent`를 명기한다.

## G5. 제품 KPI 경계 완결 (V4-05)

- **KPI ①**: p95 산식은 최근접 순위(nearest-rank), 첫 응답 기준(재시도 제외), 표본은
  배포 후 연속 7일 실측 + 합성 부하 포함 N≥100.
- **KPI ③**: 분모 = 홀드아웃 40건 평가 실행 중 생성된 모든 브리핑(N=40).
- **KPI ④**: 동일 합성 사건 **쌍체 비교**. 미포함 조건 중앙값이 0이면 감소율 대신
  "포함 조건도 0 유지 시 통과"로 판정한다.
- **KPI ⑤**: 통과 판정은 기준(규칙형) 누락률>0인 사건 부분집합으로 계산하고, 그
  부분집합 N<10이면 판정 유보(결과 공개만). 기준 누락률 0인 사건은 "비열등" 여부만
  공개한다. 확인 질문 수·브리핑 슬롯 정확도·이해도는 **통과 판정에 미관여, 공개 전용**.

## G6. 병합 출처 배열화 (V4-06)

`ActionCard.official_source: string` → **`official_sources: string[]`** — 병합된 모든
행의 출처 합집합, 표시 순서는 severity 순. 규칙 표의 "공식 출처" 열은 행 단위 출처로 유지.

## G7. 개칭 잔존 소탕 (V4-07)

두 문서에서 "이벤트 원장"·"행동 사실 원장"·"이 원장" 잔존 표현을 "행동 이벤트 이력"으로
교체한다("감사 원장이 아님"을 설명하는 문맥은 유지).
