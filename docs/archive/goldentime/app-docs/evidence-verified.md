# 골든타임 UI 정량 근거 검증본

- 확인일: 2026-07-25 (KST)
- 적용 범위: E1~E10의 외부 사실·수치와 R1~R7 행동 카드의 출처 적합성
- 판정 원칙: 발행기관의 원문, 현행 법령 원문 또는 해당 제도를 실제 운영하는 기관의 원문에 직접 접속해 문구를 확인한 경우만 승인한다. 언론 보도, 검색 결과 요약, 제3자 재게시본은 대조 자료일 뿐 승인 근거로 쓰지 않는다.
- UI 게이트: 이 문서의 **UI 사용 승인 수치 목록**에 있는 문자열만 복사해 쓸 수 있다. `⚠️부분확인` 항목에서 승인 목록에 따로 실리지 않은 값과 `❌원문미확인` 항목은 모두 UI 사용 금지다.
- 접속 확인 방법: 브라우저 본문 열람과 `curl -L` 응답을 교차 확인했다. `HTTP 000`은 서버가 빈 응답을 반환해 본문을 받지 못했다는 뜻이다.
- 범위 경계: 단계 번호·규칙 ID·기능명세가 정한 질문 상한처럼 제품이 정의한 수는 외부 관측 통계가 아니므로 기능명세와 일치하는지를 별도로 검사한다. 반면 `2분`처럼 실제 소요시간을 암시하는 UI 문구는 실측값이므로, 측정 근거가 없으면 금지한다.

## 결론

검증 대상 중 그대로 통과한 정량 주장은 E5뿐이다. E1과 E3은 핵심 제도 수치는 확인됐지만 현재 문구의 시행일·기한 단위가 틀려 수정본만 승인한다. E2는 금융감독원 원문 게시 URL을 찾지 못했으므로 설문 수치 전부를 금지한다. E4는 공식 사이트에 두 숫자가 있지만 연도와 통계 정의가 없어 `2025년 잠정 합계`로 사용할 수 없다.

현재 구현·목업에서 발견된 `3영업일` 표기는 현행 법령 원문의 `3일 이내`와 불일치한다. 이 문서는 코드나 목업을 수정하지 않지만, 해당 문자열은 릴리스 전에 반드시 교체해야 한다.

## 항목별 검증

### E1 지연인출제도

- 판정: ⚠️부분확인
- 접속 결과:
  - 제시된 금융감독원 URL: HTTP 000, 빈 응답. 브라우저 본문 요청도 시간 초과되어 원문을 직접 읽지 못했다.
  - 대체 공식 요약: HTTP 200, 페이지 제목 `전자금융범죄 > 전자금융범죄 예방대책 > 금융회사 등의 전자금융범죄 예방조치 > 지연인출·이체제도 (본문) | 찾기쉬운 생활법령정보`.
  - 운영기관 원문: HTTP 200, 페이지 제목 `자동화기기 지연인출제도 변경 안내`.
- 원문 근거 인용:
  - “1회에 100만원 이상 금액이 송금·이체되어 입금된 경우”
  - “30분간 자동화기기(CD/ATM기 등)를 통한 인출·이체가 지연”
  - 수협은행 변경 공지: “지연인출 기준금액이 300만원에서 100만원으로 변경”
- 수치 대조:
  - `1회 100만 원 이상`, `30분`, `CD/ATM 인출·이체`는 확인됐다.
  - `2012.11 시행`은 확인되지 않았다. 금융위원회 2012-06-05 원문은 당시 기준을 `300만원 이상`, `10분`으로 적고 있고, 수협은행의 제도 변경 원문은 현재 기준의 시행일을 `2015년 9월 2일`로 적는다.
  - 금융위원회 원문에서 `’12.11월`은 보이스피싱 **합동경보제**의 도입 시점으로 쓰인 사례가 확인된다. 이를 현재 지연인출 기준의 시행일로 옮겨 쓸 수 없다.
- UI 확정 표기: `1회에 100만 원 이상이 송금·이체되어 입금된 경우, 입금된 때부터 해당 금액 상당액 범위에서 30분간 CD/ATM을 통한 인출·이체가 지연됩니다.`
- 병기 필수 조건: 1회 100만 원 이상 입금 건의 해당 금액 상당액에만 적용되며, 금융회사 창구에서는 즉시 인출·이체할 수 있다. 사용자의 개별 거래에 남은 시간을 뜻하지 않는다.

### E2 금융감독원 2021년 피해자 설문

- 판정: ❌원문미확인
- 접속 결과:
  - 농민신문: HTTP 200, 페이지 제목 `보이스피싱 피해 4명중 3명 골든타임 놓쳐`.
  - 보안뉴스: HTTP 200, 페이지 제목 `연령별로 잘 걸리는 보이스피싱 피해 수법 달랐다`.
  - 금융감독원 `fss.or.kr` 및 정책브리핑 `korea.kr`의 원문 게시 URL: 탐색했으나 미발견.
  - 금융감독원 보도자료 파일의 제3자 재게시본: 신한카드 PDF HTTP 200.
  - 공공기관 재게시 메타데이터: KDI 경제교육·정보센터 HTTP 200.
- 원문 근거 인용: 없음. 발행기관 원문 게시 URL을 확보하지 못했다.
- 미통과 대조 자료: 금융감독원 보도자료 형식의 재게시 PDF에는 “피해 인지시점이 30분 이내인 경우는 25.9%에 불과”라고 적혀 있고, 표에는 `20대 이하 31.3%`, `30·40대 35.2%`, `50·60대 이상 19.7%`가 있다. 조사 대상 `620명`도 적혀 있다. 그러나 이 파일은 금융감독원이나 정책브리핑 원문 URL이 아니다.
- 수치 대조:
  - `620명`, `25.9%`, `19.7%`, `35.2%`, `31.3%`는 재게시본 및 언론 보도끼리는 일치한다.
  - `161명`은 재게시된 금융감독원 보도자료 파일에 없다. 농민신문에만 있고, 반올림된 비율에서 실제 응답자 수를 역산해 확정할 수도 없다.
- UI 확정 표기: 없음. E2의 모든 수치는 UI 사용 금지다.
- 병기 필수 조건: 원문 게시 URL을 확보해 재검증하기 전에는 주석·툴팁·심사자료를 포함한 어떤 UI에도 수치를 표시하지 않는다.
- 원문 탐색 기록:
  - `fss.or.kr`에서 정확한 제목 `보이스피싱 피해자 설문조사 분석결과`, `620명`, `25.9%`, `2021.7.1`, 담당부서 `불법금융대응단`을 조합해 검색했다.
  - 금융감독원 구형 보도자료 경로와 현행 게시판 경로를 각각 검색했다.
  - `korea.kr`에서 정확한 제목과 수치 조합을 검색했다.
  - 발견된 것은 언론 보도, [KDI 재게시 메타데이터](https://eiec.kdi.re.kr/policy/materialView.do?num=215555), [신한카드 서버의 PDF 재게시본](https://www.shinhancard.com/pconts/download/person/20210705577317.pdf)뿐이었다.
  - 재게시본 메타데이터상 제목은 `보이스피싱 피해자 설문조사 분석결과`, 발행기관은 금융감독원, 담당부서는 불법금융대응단, 배포일은 2021-06-30, 보도일은 2021-07-01이다. 이는 원문 URL 발견을 대신하지 못한다.

### E3 전화·구술 신청의 서면 후속과 피해환급금 결정

- 판정: ⚠️부분확인
- 접속 결과:
  - 제시된 URL: HTTP 200, 페이지 제목 `전자금융범죄 > 전자금융범죄 피해구제 > 전기통신금융사기 피해구제 > 지급정지 (본문) | 찾기쉬운 생활법령정보`. 이 페이지에는 두 목표 기한이 모두 있지 않다.
  - 피해구제 신청 페이지: HTTP 200, 페이지 제목 `전자금융범죄 > 전자금융범죄 피해구제 > 전기통신금융사기 피해구제 > 피해구제 신청 (본문) | 찾기쉬운 생활법령정보`.
  - 피해환급금 페이지: HTTP 200, 페이지 제목 `전자금융범죄 > 전자금융범죄 피해구제 > 전기통신금융사기 피해구제 > 피해환급금 결정·지급 및 소멸채권 환급 청구 (본문) | 찾기쉬운 생활법령정보`.
  - 국가법령정보센터 시행령 제3조·법 제10조: 각각 HTTP 200.
- 원문 근거 인용:
  - “신청한 날부터 3일 이내에 피해구제신청서를 해당 금융회사에 제출하여야 합니다”
  - “채권이 소멸된 날부터 14일 이내에 피해환급금을 지급받을 자 및 그 금액을 결정”
- 수치 대조:
  - 현행 시행령은 `3영업일`이 아니라 `3일 이내`라고 규정한다.
  - `14일 이내`는 피해환급금의 **수령자와 금액을 결정하는 기한**이다. 실제 지급 완료 기한이 아니다.
- UI 확정 표기:
  - `긴급하거나 부득이한 사유로 전화 또는 구술로 피해구제를 신청한 경우, 신청한 날부터 3일 이내에 피해구제신청서를 해당 금융회사에 제출해야 합니다.`
  - `금융감독원은 채권이 소멸된 날부터 14일 이내에 피해환급금을 지급받을 사람과 금액을 결정합니다.`
- 병기 필수 조건: 첫 문장은 단순한 모든 `전화 지급정지 요청`이 아니라 긴급하거나 부득이한 사유로 한 `전화 또는 구술 피해구제 신청`의 후속 절차다. 둘째 문장은 채권소멸 절차가 끝난 뒤의 결정 기한이다.

### E4 2025년 보이스피싱 잠정 합계

- 판정: ⚠️부분확인
- 접속 결과:
  - 제시된 방송미디어통신위원회 PDF: HTTP 200, 문서 제목 `범정부 보이스피싱TF, 7개월 연속 피해 감소 성과...“신종 스캠범죄 대응에 총력”`, 보도 2026-05-27.
  - 경찰청 전기통신금융사기 통합대응단 홈페이지: HTTP 200, 페이지 제목 `피싱안심SOS`.
- 원문 근거 인용: “23,360건 연 국내 신고 접수량 / 1조 2578억 국가적 손실액”
- 수치 대조:
  - 제시된 PDF에는 `23,360건`과 `1조 2,578억 원`이 없다.
  - 통합대응단 홈페이지에는 두 숫자가 있지만 기준 연도, 잠정 여부, 범죄·신고의 집계 정의가 표시되지 않는다.
  - 따라서 `2025년 보이스피싱 피해 잠정 합계`라는 기간·정의를 두 숫자와 결합할 수 없다.
- UI 확정 표기: 없음. `23,360건`, `1조 2,578억 원`을 2025년 합계로 표시하는 것은 금지한다.
- 병기 필수 조건: 향후 연도·집계 정의가 명시된 경찰청 통계 원문을 확보하기 전에는 두 숫자를 통계 카드에 사용하지 않는다.

## 유지·재검증 조건

- 게시물 삭제·이동 또는 법령 개정이 확인되면 해당 문자열을 즉시 `미확인`으로 되돌리고 재검증한다.
- 2026-10-01 시행 예정인 관련 특별법 명칭·용어 변경 전후로 E3의 법령 링크와 UI 용어를 다시 확인한다.
- E2는 금융감독원 또는 정책브리핑의 원문 게시 URL을 확보하기 전까지 금지 상태를 유지한다.
  **2026-07-25 오케스트레이터 독립 재탐색에서도 미발견**(`fss.or.kr`·`korea.kr`·`fsc.go.kr`
  도메인 한정 검색 + 일반 검색 2회). 금감원 보도자료 목록
  (`https://www.fss.or.kr/fss/bbs/B0000188/list.do?menuNo=200218`)과 보이스피싱지킴이
  보도자료 목록(`https://www.fss.or.kr/fss/bbs/B0000052/list.do?menuNo=200358`)에서
  `620명`·`25.9%` 표기를 확인하지 못했다. 2021년 피해현황 분석 보도자료(2022-04 게시)에는
  환급률 35.9%·피해자 13,204명 등 **다른 지표**가 실려 있어 설문 원문과 다른 문서다.
  독립 탐색 2회 실패이므로 금지 상태를 유지하고, 원문 확보 시 개정 계약으로 복원한다.
- E4는 기준 연도와 집계 정의가 함께 적힌 경찰청 원문을 확보하기 전까지 금지 상태를 유지한다.
- 행동 카드에서 출처 하나가 행동 전체를 지지하지 않으면, 표에 적은 대체 공식 출처를 함께 연결하거나 지지되지 않는 동사를 제거한다.
