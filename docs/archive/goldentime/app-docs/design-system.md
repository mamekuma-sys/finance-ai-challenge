# 골든타임 사기대응 데스크 디자인 시스템

버전: `GT-DS 0.1`  
적용 범위: F-01~F-11, F-13, F-21 소비자 데스크와 상태 전환 비교 뷰  
계약 기준: `docs/planning/11-spec-draft.md` §3.2, §3.3, §4.4, §4.5, §7

## 1. 디자인 원칙

1. **차분한 상황실:** 공포를 키우는 전면 적색 화면을 쓰지 않는다. 넓은 슬레이트 배경과
   백색 표면을 기본으로 하고, 앰버는 현재 순서와 서비스 정체성에만 제한한다.
2. **첫 행동이 주인공:** 1순위 행동의 제목을 페이지의 가장 큰 문장으로 둔다. 판정, 근거,
   출처, 버전은 행동 아래나 접이식 영역으로 보낸다.
3. **순서가 구조:** 행동 카드 왼쪽의 세로 행동 레일과 순번 배지는 장식이 아니라
   `priority` 1~4를 표현한다. 카드가 접혀도 순번은 연속으로 유지한다.
4. **색보다 문장:** 위험도, 상태, 변경점, 이벤트 출처는 색과 함께 항상 텍스트 라벨을
   표시한다.
5. **공식 행동은 고정:** 긴급 행동·기관 연락처·법적 문구는 LLM 자유 생성 영역이 아니다.
   카드에 규칙 ID, 공식 출처, 템플릿 버전을 추적 정보로 제공한다.

시각적 시그니처는 **골든 레일**이다. 1순위 배지만 채운 앰버 원으로 강조하고 나머지는
선과 외곽선으로 연결한다. 금빛 그라디언트, 장식적 타이머, 경보 애니메이션은 사용하지
않는다.

## 2. 컬러 토큰

### 2.1 계산 방법과 판정 기준

아래 수치는 WCAG 상대휘도 공식을 직접 적용한 결과다.

```text
sRGB 채널 c = 8bit / 255
c <= 0.04045 이면 c_lin = c / 12.92
그 외 c_lin = ((c + 0.055) / 1.055) ^ 2.4
L = 0.2126 R_lin + 0.7152 G_lin + 0.0722 B_lin
contrast = (L_lighter + 0.05) / (L_darker + 0.05)
```

- 일반 본문과 라벨: 4.5:1 이상
- 18px 이상 일반 또는 14px 이상 굵은 큰 글자: 3:1 이상
- 입력·버튼·카드의 정보성 경계와 포커스 링: 인접 배경 대비 3:1 이상
- 배경과 표면의 미세한 명도 차는 정보를 전달하지 않는다. 모든 정보성 표면에는
  `border-strong`을 둘러 경계를 3:1 이상으로 만든다.
- 표의 비율은 소수 셋째 자리에서 반올림했다.

## 3. 타이포그래피

외부 폰트 요청은 사용하지 않는다.

```css
font-family:
  -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo",
  "Malgun Gothic", "Noto Sans KR", sans-serif;
```

한글은 영문보다 글자 내부가 조밀하므로 본문 line-height를 1.65 이상으로 둔다. 본문 자간은
`-0.01em`, 큰 제목은 `-0.035em`, 작은 유틸리티 라벨은 `0.02em`을 사용한다. 한글 전체를
대문자처럼 벌리는 과도한 자간은 금지한다.

| 토큰 | 크기 / 행간 / 굵기 | 용도 |

| `h1` | `clamp(28px, 4vw, 44px) / 1.2 / 750` | 페이지 제목 |

## 5. 레이아웃 그리드

- 전체 너비: `min(100% - 32px, 1100px)`, 360px에서는 좌우 16px
- 데스크톱: 12열, 24px 거터. 행동 레일 8열 + 증거·금지 행동 보조면 4열
- 태블릿: 8열, 20px 거터. 768px 이하에서 한 열로 전환
- 모바일: 4열, 16px 거터. 카드·버튼·상태 칩은 컨테이너 너비를 넘지 않는다.
- 긴 문자열: URL·템플릿 ID는 `overflow-wrap:anywhere`
- 비교 뷰: 900px 이상에서 2열, 그 아래에서는 `이전 상태 → 변경 상태` 문서 순서로 적층
- 상태 필드는 `auto-fit, minmax(min(100%, 220px), 1fr)`로 배치
- 표는 작은 화면에서 카드형 목록으로 바꾸거나 각 셀에 `data-label`을 제공한다. 페이지 전체
  가로 스크롤로 해결하지 않는다.

## 6. 공통 인터랙션 상태

모든 컴포넌트는 아래 상태를 구현한다. 개별 표의 상태는 이 공통 계약에 추가되는 차이만 적는다.

| 상태 | 라이트 | 다크 |
|---|---|---|
| default | surface + 1px `border-strong` | surface + 1px `border-strong` |
| hover | `translateY(-1px)`, 경계 2px, shadow-1 | `surface-muted`, 경계 2px |
| focus-visible | 3px `focus.ring`, offset 3px | 3px `focus.ring`, offset 3px |
| active | 변형 제거, shadow 제거, `brand.gold` 3px inset | 변형 제거, `brand.gold` 3px inset |
| disabled | opacity을 쓰지 않고 muted 면 + muted 텍스트 + `사용 불가` 텍스트, `cursor:not-allowed` | 동일 |

비활성 상태에서 낮은 opacity만 사용하면 대비가 무너지므로 금지한다.

## 7. 컴포넌트 명세

### 7.1 긴급 질문 선택지 버튼

- 네이티브 `<button type="button">`, 일반 모드 최소 48×48px, 고령자 56px 높이
- 질문 한 문장 뒤에 세로 버튼 그룹을 둔다. 긴급 상태는 한 줄 두 버튼보다 세로 배치를 우선
- default: 좌측에 명시적 선택 라벨, 우측에 상태값 텍스트
- hover: 배경만 `surface-muted`; 레이아웃 이동 없음
- focus: 공통 3px 링과 `aria-describedby` 질문 연결
- active/selected: `선택됨` 텍스트 + 3px 골드 인셋, 필요 시 `aria-pressed=true`
- disabled: `사용 불가` 텍스트, 이유를 인접 설명으로 제공
- 다크: 동일 구조, 골드 면 위 글자는 `brand.ink`

### 7.2 상태 필드 라디오 그룹

- 반드시 `<fieldset><legend>…</legend>` 구조
- 라디오와 라벨 전체가 최소 44px 타깃; 고령자 모드 56px
- default: 1px 강한 경계, 선택 상태는 `선택됨` 문구 포함
- hover: 라벨 배경 `surface-muted`
- focus: 실제 input의 `:focus-visible + label`에 링
- active: 3px 골드 인셋
- disabled: `사용 불가` 텍스트와 이유
- 오류: `aria-invalid=true`, `role=alert` 설명. 적색만 쓰지 않고 `확인이 필요합니다` 문장
- 다크: 라디오 내부 점은 골드, 외곽선은 `border-strong`

### 7.3 행동 카드

구조:

```text
[순번 배지 + “지금 먼저”] [필수 카드]
제목
목적
  • purpose_slot
[전제 조건]
[행동 버튼]
공식 출처 · 템플릿 버전
▸ 왜 이 순서인가
```

- `<article aria-labelledby>`를 사용하고 순번은 `<span aria-label="행동 1">1</span>`
- 1순위 카드만 `radius-xl`, `shadow-2`, 2px 골드 경계. 나머지는 `radius-lg`
- `purpose_slots`는 불릿 목록으로 모두 보존하며 병합 과정에서 숨기지 않는다.
- 전제 조건은 `전제 조건` 텍스트와 함께 `surface-muted` 블록에 둔다.
- 공식 출처는 기관·문서명을 링크 텍스트로 사용한다. “여기” 링크 금지
- 템플릿은 모노스페이스가 아니라 유틸리티 글꼴로 표시하고 줄바꿈 허용
- `왜 이 순서인가`는 네이티브 `<details><summary>`로 구현한다.
- 전역 서면 후속 카드는 `필수 카드` 텍스트 라벨을 항상 표시한다.
- hover: 카드가 아닌 카드 안의 실제 버튼과 링크만 반응. 카드 전체 클릭 금지
- focus: 각 링크·버튼·summary에 개별 링
- active: 실제 컨트롤에만 인셋 표시
- disabled: 카드 자체를 비활성화하지 않는다. 실행 불가 행동은 버튼에 `사용 불가`와 이유
- 다크: 순번 색과 의미는 유지하고 surface·경계 토큰만 전환

### 7.4 금지 행동 블록

- `<aside aria-labelledby>`와 제목 `하지 마세요`
- 항목마다 텍스트 `금지` 라벨 + 문장을 제공한다. X 아이콘만 사용하지 않는다.
- 라이트: `#FFF1F2` 면, `#9B2C2C` 경계, `#7F1D1D` 글자
- 다크: `#35191F` 면, `#FF8A8A` 경계, `#FFB4B4` 글자
- hover/active 없음. 내부 링크가 있다면 공통 링크 상태만 적용
- focus: 내부 링크·버튼에 공통 링
- disabled 없음. 현재 규칙에 해당하지 않으면 컴포넌트를 DOM에서 제거하고 `aria-live`로
  상태 변경을 알린다.

### 7.5 고정 문구 복사 카드

- `<section>` 안에 고정 문구, 출처, 템플릿 버전, `문구 복사` 버튼
- 복사 버튼은 최소 48px. 성공 시 버튼 텍스트를 `복사됨`으로 바꾸고 `aria-live=polite`
- hover: surface-muted, focus: 공통 링, active: 골드 인셋
- disabled: 클립보드 미지원 시 `복사 사용 불가`와 전체 선택 가능한 원문 유지
- 다크: 문구 영역을 muted surface로, 선택 영역은 시스템 선택색을 존중

### 7.6 상태 전환 비교 뷰

- 2열 각각 `<section aria-labelledby>`; 상단에 상태 필드 요약
- 변경점은 `추가`, `제거`, `순위 변경` 텍스트 배지와 `+`, `−`, `↕` 기호를 함께 표시
- 모바일 문서 순서는 이전 상태 다음 변경 상태
- hover: 비교 행의 두 대응 항목을 함께 강조하되 색만 바꾸지 않고 2px 경계 추가
- focus: 대응 항목이 버튼이면 공통 링, 정적 행은 포커스 불필요
- active: 선택한 변경 필터 버튼에 `aria-pressed=true`와 `선택됨`
- disabled: 해당 변경 유형이 없으면 `변경 없음` 텍스트
- 다크: §2.6의 다크 비교 배지 쌍 사용

### 7.7 행동 이벤트 이력 타임라인

- 제목은 반드시 `행동 이벤트 이력(내 기기 보관)`
- `<ol>`로 append 순서를 표시하고 이벤트마다 시각·상태·이전 상태·출처를 텍스트로 제공
- `ui_event`는 `자동 관측`, `user_statement`는 `사용자 진술` 배지로 표시
- 정정은 `정정`과 `corrects_event_id`를 텍스트로 표시
- hover: 행 배경 muted, focus: 행 안의 정정 버튼에 공통 링
- active: 선택한 이벤트에 좌측 3px 골드 바 + `선택됨`
- disabled: 허용되지 않은 전이는 `기록 거부`와 이유를 `role=alert`로 표시
- 다크: 출처 배지의 외곽선 3:1 이상 유지

### 7.8 신뢰 고지 바

- 화면 상단에 `합성 샘플 · 무로그인 · 서버 무저장` 세 라벨을 텍스트로 고정
- 하단 F-21 고지에는 `오분류 가능성`, `공식 채널 재확인`, `실제 처리 권한 부재`,
  `공식 출처`를 모두 표시
- default: surface + strong border. 상단 sticky 사용 시 포커스를 가리지 않도록
  `scroll-padding-top`을 설정
- hover/active 없음. 링크만 공통 상태
- focus: 공식 출처 링크에 공통 링
- disabled 없음
- 다크: muted surface와 strong border

## 8. 색만으로 의미를 전달하지 않는 규칙

| 색 사용처 | 반드시 병기할 텍스트 |
|---|---|
| 위해 순위 빨강~슬레이트 | `위해 순위 1`~`위해 순위 7` |
| 현재 골드 순번 | `지금 먼저` |
| 전역 후속 카드 골드 경계 | `필수 카드` |
| 성공 초록 | `확인됨` |
| 정보 파랑 | `안내` |
| 경고 앰버 | `주의` |
| 거부 적색 | `기록 거부` + 이유 |
| 비교 초록 | `추가` + `+` |
| 비교 적색 | `제거` + `−` |
| 비교 앰버 | `순위 변경` + 이전/이후 순위 |
| 적색 금지 블록 | `하지 마세요` + 각 항목의 `금지` |
| 이벤트 출처 | `자동 관측` 또는 `사용자 진술` |
| 합성 데이터 | `합성 샘플` 또는 `합성 사건 전용` |

## 9. 모션

- 기본 전환: 배경·경계·transform `180ms ease-out`
- 접이식 근거: 브라우저 네이티브 동작을 우선하며 커스텀 애니메이션을 쓰면 최대 250ms
- 버튼 active: 150ms 이하
- 경보 점멸, 무한 펄스, 자동 카운트다운, 흔들림 금지
- 가짜 로딩·인위적 지연·가짜 단계 이벤트 금지
- 긴급 안전 카드는 결정적 규칙 결과가 준비되는 즉시 표시

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

## 10. 접근성 검수 체크

- 200% 확대와 360px 너비에서 콘텐츠·포커스가 잘리지 않는다.
- Tab 순서는 상단 건너뛰기 링크 → 테마 → 1순위 행동 → 다음 행동 → 근거 → 하단 고지다.
- 동적 상태 변경은 `aria-live=polite`, 기록 거부는 `role=alert`로 알린다.
- 아이콘은 장식이면 `aria-hidden=true`; 단독 아이콘 버튼은 만들지 않는다.
- 링크는 목적을 문장 자체로 설명한다.
- 외부 공식 링크에는 새 창을 강제하지 않는다.
- 브라우저 기본 고대비와 `forced-colors`에서 배지 경계와 포커스가 유지된다.
- 라이트·다크 모든 실제 텍스트/배경, 경계/배경 조합은 §2의 계산값을 사용한다.
