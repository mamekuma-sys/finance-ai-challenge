### 이번 확정에서 바꾼 4가지

1. **축 이동** — 「사전 증거보전」 → **「사후 증적 복원」**. 원안 자기반증("사고 전엔
   아무도 켜지 않는다")이 소멸하고 **오늘 당장 사용 가능**해진다. 근거: 공개 신고서식 p.3이
   기억으로 묻는 7항목의 답이 이미 이용자 기기에 있다.
2. **문제 재정의** — 피해 규모가 아니라 **두 개의 관문**. 깔때기를 한 출처·한 기간·한
   모집단으로 확보: **상담 2,135 → 신청 173 → 심사제외 60(34.7%) → 배상 18(상담 대비
   0.84%)** (5대 은행, 2024-01~2025-08, 이인영 의원실). **최대 손실 구간은 「상담→신청」
   91.9%** — 이것이 모수 반박("연 173건 시장")에 대한 답이다.
3. **A-면(에이전트 면) 신설** — 3면 구조(소비자/은행 심사역/에이전트).
   `llms.txt`·`/agent`·공개 조회·계산 API·MCP·DOM 판독성·결정 재현성.
   **닫은 것이 더 중요**: 제출 API 없음·쓰기 없음·무로깅·무저장·확률 필드 없음.
   기획서 자유 항목(§7) = "에이전트에게 무엇을 열고 무엇을 닫았는가".
4. **D2 확보** — 「타임라인 재생」은 D2로 약하므로 **반사실 시뮬레이터**로 교체
