# 기획·명세 작업

주제 확정(`docs/research/03-decision.md`) 후 이 폴더에서 제출물을 작성한다.

## 작업물

- 데이콘 제공 양식 원본 (기획서·기능명세서) — 다운로드 후 이 폴더에 보관
- `기획서-draft.md` — 기획서 초안 (양식 항목 기준으로 작성 → 양식에 옮겨 PDF 변환)
- `기능명세서-draft.md` — 기능명세서 초안
- `mvp-scope.md` — MVP 기능 범위: must-have / nice-to-have 구분, 데모 시나리오

## 원칙

- 양식이 요구하는 항목을 먼저 파악하고 기획을 역산한다.
- MVP 범위는 "심사위원이 30초 안에 핵심 가치를 체험"할 수 있게 최소화한다.
- 기능명세서에 적은 기능은 배포 URL에서 전부 실제 작동해야 한다.
