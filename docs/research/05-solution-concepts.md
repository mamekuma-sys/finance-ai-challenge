# 부서 스케일 솔루션 컨셉 — 전 기관 재점검 (2026-07-24)

## 재설계 기준

기존 후보 21개는 "기능(feature)" 레벨이었다. 재설계 기준: **금융회사 조직도에 실존하는 부서 중,
AI 멀티에이전트가 그 부서의 업무 전 주기를 재현할 수 있는 것**. 평가 축은 사용자 요구 그대로:

1. **Uniqueness** — 다른 참가자가 안 만들 것 / 기존 서비스와 차원이 다를 것
2. **Business impact** — 검증된 수치로 부서 단위 가치를 증명할 것
3. **부서 스케일** — 단일 기능이 아니라 역할이 분리된 에이전트들이 협업하는 조직일 것
4. **Visually appealing demo** — 상황실·대시보드·라이브 시연이 극적일 것

모든 인용 수치는 검증 통과분(`04-verification-digest.md`)만 사용.

## 컨셉 1. AI 사기대응 상황실 (Fraud Response Operations Center) ★추천

> "은행 금융사기대응팀 + 피해자 케어 데스크"를 통째로 재현하는 워룸

**재현하는 실제 부서**: 은행 사기대응팀(FDS 경보 처리), 콜센터 사기신고 데스크, 기관 간 정보공유 담당

**검증된 부서의 고통**:
- FDS 요원은 인력 부족 상태로 고객 응대에 평균 ~20분/건 (헤럴드경제 현장 보도, fsi 검증 대체출처)
- 8개 은행 2.5년 피해 34,156건·4,697억원, FDS 사전탐지 ~15% (국회 분석)
- 5대 은행 임시조치 15.8만 건 중 기관 간 공유 869건 — 공유가 수작업 병목
- 피해자 측 대화형 판단보조는 검증 생존 ✅ 2개가 수렴한 공백

**부서 구성 (멀티에이전트)**:

| 에이전트 | 역할 (사람 부서의 대응 직무) |
|---|---|
| 트리아지 | 경보 스트림 수신 → 위험도·긴급도 분류 (주니어 분석가) |
| 사건 분석가 | 계좌·전화번호·URL 관계 그래프 구축, 수법 분류, 유사 사건 매칭 (시니어 분석가) |
| 피해자 케어 | 연령·언어 맞춤 대화 — 근거 설명→확인 질문→쿨링오프 (상담사) |
| 조치 오케스트레이터 | 지급정지→신고(1394/112)→증거 보존→타기관 공유를 사람 승인 게이트와 함께 실행 (대응 담당) |
| 리포터 | 경찰 제출용 증거 패키지, 사건 요약, 월간 트렌드 경영 보고 (보고 담당) |
| QA 하네스 | 합성 시나리오 오분류율·유해 안내 차단 자동 평가 (품질 관리자) |

**Business impact**: 사건당 처리 시간 20분→분 단위, 공유 자동화(869건/15.8만 병목 해소),
골든타임 내 지급정지 도달률 — 3개 지표 모두 데모에서 측정·표시 가능

**데모 (30초 시나리오)**: 워룸 대시보드에 합성 사건이 라이브로 흘러들어옴 → 사건 클릭 →
관계 그래프가 펼쳐지고 에이전트 6개의 협업 타임라인이 실시간 진행 → 화면 분할로 피해자
대화(고령자 모드) 동시 시연 → 골든타임 타이머 종료 전 지급정지 완료 → 증거 패키지 PDF 생성

**수상 각도**: 최우수상(금보원 ASAP·정보공유 전략의 "다음 단계") + 대상(범정부 TF) 투 트랙.
카뱅 우수상 각도 겸비. v2 확장: 보험사기 모듈(생보협)·연합 시나리오

**Uniqueness 방어**: 예시 3번 참가자들은 "행동 요령 챗봇(비서)"을 낼 것. 이 컨셉은 비서가
아니라 **부서** — 양면 시스템 + 사건 오케스트레이션 + 증거·보고 산출물 + QA 하네스가 차원 분리

**흡수하는 기존 후보**: 금보원-1, 금융위-3, 카뱅-3 (검증 생존·재정의분 전부)

## 컨셉 2. AI 민원·분쟁 해결실 (Complaint & Dispute Resolution Office) — 다크호스

> 폭증하는 금융민원을 접수→근거 재구성→판정 초안→소비자 설명까지 처리하는 부서

**재현하는 실제 부서**: 금융회사 소비자보호부·민원팀, 협회 옴부즈만, 분쟁조정 대응팀

**검증된 부서의 고통**:
- 2025년 금융민원 116,338건, 전년 대비 **+24%** (은행 +53.3%) — 부서 과부하가 공식 통계로 입증
- 보험업권 상반기 민원 28,137건, 생보 보험금 지급 민원 +13.6% (2023 생보 민원 중 지급 유형 21.8%)
- 2026년부터 단순민원의 협회 이송 제도 시행 — 처리 주체 재편 중 (KLIA 확인)
- 소비자는 지급·거절 판정의 약관 근거를 재구성할 수단이 없음 (보비·보움은 청구 전 단계에 집중)

**부서 구성**: 접수·분류 에이전트 → 사실관계 정리 → 약관·규정 근거 재구성(조항 인용 강제)
→ 판정 초안(담당자용) + 쉬운 설명(소비자용) 이중 출력 → 이의제기·분쟁조정 절차 안내 →
SLA·유형 트렌드 대시보드 → 감독 보고 자동화

**Business impact**: 건당 처리 시간·처리 원가, 분쟁조정 전 단계 해결률, 민원 재발 유형 탐지

**데모**: 민원 인입 스트림 보드 → 민원 클릭 → 약관 조항 하이라이트와 증빙 타임라인이
좌우로 맞물림 → '충족/누락/확인 필요' 카드 → 소비자용·담당자용 문서 동시 생성

**수상 각도**: 금융위(소비자보호 아젠다)·생보협·은행권. **약점: 주최(금보원) 정합성이 낮음**

**Uniqueness**: 최상 — 민원 부서를 만들 참가자는 없을 것. 흡수: 생보협-1, KB-1의 근거 추적 엔진

## 컨셉 3. 중소 금융회사 AI 보안실 (Virtual Security Office) — 기술 깊이 최강

> 보안 인력이 없는 중소 금융회사·핀테크에게 "가상 보안 부서"를 제공

**재현하는 실제 부서**: 중소 금융회사의 보안팀 — 정확히 금보원이 2026년 AI보안지원센터를
신설한 이유("AI 위협 대응이 어려운 중소 금융회사 지원", 검증됨)

**검증된 고통**: 취약점 평가 15개 분야·869개 항목(178개사), 생성형 AI 혁신서비스 169건
지정·45건 출시 — 모델 변경 시 영향도 분류·증적 부담(2026-04 3단계 절차), 프론티어 AI 공격
(세부 주제 예시 7번 직결)

**부서 구성**: 관제 이벤트 트리아지 → 취약점 우선순위·실행계획 → 생성형 AI 변경 자동
레드팀(공격 프롬프트 스위트)+증적 패키지 → 경영진 1페이지 보고

**데모**: SOC 대시보드 + **라이브 레드팀 시연**(배포 전/후 모델에 같은 공격 10개를 실시간
주입, 위험 레이더·출력 diff가 갈라지는 장면) — 시각 임팩트 최상급

**수상 각도**: 금보원 정조준 + 예시 7번. **약점: 금보원이 직접 확대 중인 기능과 인접**(검증
지적 — "평가 대행"이 아니라 "평가 준비 도구"로 좁혀야), B2B라 심사위원 체험 서사 설계 필요

**Uniqueness**: 매우 높음. 흡수: 금보원-2·3

## 컨셉 4. AI 소상공인 금융주치의실 — 대상 정합성 카드

> 서민금융 상담 창구의 "진단→처방→서류→사후관리" 전 주기를 부서로

**검증된 고통**: 정책자금 3조7,700억 분산 + 별도 10조 맞춤형, 특별채무조정 143만 명,
소상공인 특화 신용평가모형 추진 (금융위 검증 확인)

**부서 구성**: 자연어 진단 → 요건 추출·자격 판정(탈락 사유·근거 문장) → 서류 사전심사 →
현금흐름 14~30일 예측·원인 분해 → 상담 준비 패키지 → 사후 상환 관리

**약점**: 기업마당·소상공인24·서민금융 잇다·하나 맞춤조회 등 기존 서비스 최다 — 부서 프레임으로
격상해도 "매칭 서비스의 확장"으로 읽힐 위험. Uniqueness 4개 중 최하
