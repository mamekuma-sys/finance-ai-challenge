# 금융위원회(FSC) 딥리서치 개요

조사 기준일: 2026-07-24. 최근 12개월은 2025-07-24~2026-07-24로 보았다. 금융위가 원하는 문제는 단순한 금융상품 추천보다 **생산적 금융을 실제 수요자에게 연결하고, 취약계층의 접근성을 높이며, AI 전환의 신뢰·보안을 확보하는 것**으로 수렴한다.

## 2. 기관이 지금 풀고 싶은 문제

1. 돈이 부동산·대기업에 쏠리지 않고 지방·혁신기업·소상공인으로 흐르게 하는 것.
2. 지원 규모를 늘리는 동시에 청년·저신용자·연체자에게 실제 도달시키는 것.
3. 점포 축소와 디지털 전환이 고령층·장애인의 금융 배제로 이어지지 않게 하는 것.
4. 보이스피싱·신종 스캠을 데이터 공유와 AI로 탐지하되 피해자 구제까지 연결하는 것.
5. 금융권 AI를 허용하면서도 설명가능성, 인간 최종책임, 보안, 금융소비자 이익을 지키는 것.

## 3. 접근성 지표의 한계

청년은 정책상품의 연령·소득·가구요건이 명확하지만, 외국인의 금융 접근성(계좌·대출 거절률 등)을 금융위가 최근 공식 수치로 집계한 자료는 이번 조사에서 확인하지 못했다. 통계청 이민자체류실태조사는 소득·지출·경제적 어려움·언어능력을 조사하도록 개편됐으나 금융상품 접근률 자체는 확인 불가다. 따라서 외국인 문제는 정량 수치를 과장하지 않고 ‘언어·서류·신용이력의 제도적 마찰’ 가설로 다뤄야 한다.
