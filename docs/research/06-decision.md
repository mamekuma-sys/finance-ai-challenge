## 1. 문제 정의 — 30초 훅과 정확한 서술 (이층 구조)

**훅 (발표 오프닝·랜딩 헤드라인용)**:

> **"여러분 휴대폰에도 지금 사기 문자가 한 통쯤 있을 겁니다. 지금 붙여넣어 보세요 —
> 30초 뒤, 부서 하나가 당신을 위해 움직입니다."**
>
> (발표 심사에서 심사위원이 자기 휴대폰의 실제 스팸 문자를 붙여넣게 하는 참여형 훅 —
> 데모가 곧 훅이 된다)

**정확한 문제 서술 (기획서용 — 부재 단정 없이)**:

> 보이스피싱 피해 연 1조 2,578억 원(2025 잠정)·2만 3,360건. 탐지 앱, 악성앱 검사 앱,
> 신고 전화(1394·112), 지급정지 제도는 **각각 존재하지만 서로 연결되어 있지 않다.**
> "이거 사기인가?" 싶은 순간의 국민은 흩어진 수단들 사이에서 무엇을 어떤 순서로 써야 할지
> 스스로 판단해야 하고, 그 사이 분 단위의 골든타임이 소모된다. 공급자 쪽도 마찬가지다 —
> 콜센터 사기 상담은 평균 ~20분/건(인력 부족), 기관 간 임시조치 공유는 15.8만 건 중 869건.
> **모두가 '단편'을 갖고 있고, 아무도 '완주'를 담당하지 않는다.**

- 탐지(연합학습 공동모델·시퀀스 FDS)와 신고 채널(1394·112·일괄지급정지)은 이미 존재 —
  비어 있는 것은 그 사이의 **판단보조·행동 오케스트레이션** (검증 생존 ✅ 2건 수렴)
- 정부 공식 프레임 준수: 피해는 최근 감소 추세(2025.10~2026.4 −35.3%)이나 메신저·SNS 신종
  스캠 풍선효과가 새 위협 — "폭증" 프레임 금지
- 뒷받침 수치(전부 검증 통과): 소비자 97.9%가 금융사고 가능성 우려, 90.6%는 보안 위해 불편
  감수 의사 / 은행 임시조치 15.8만 건 중 기관 간 공유 869건 / 8개 은행 FDS 사전탐지 ~15%
- 미검증 가설로 관리: "행동 지연이 피해를 키운다"(사용자 실험으로 검증). 골든타임 수치는
  공식 출처 확보 완료(2026-07-24) — `docs/planning/01-golden-time-sources.md`의 확정 표기만
  인용(지연인출제도 30분 · 금감원 2021 설문 30분 내 인지 25.9%)

## 2. 타깃 페르소나 (금융소비자 특성 × 채널 — 대회 설명문 직결)

| 페르소나 | 상황 | 채널·모드 |
|---|---|---|
| ① 순간의 의심자 (전 연령) | 문자·카톡·전화 직후 "이거 사기인가?" | 웹 데스크: 붙여넣기·캡처 업로드 |
| ② 골든타임 피해자 | "방금 돈을 보냈어요" | 골든타임 모드: 경과 타이머 + 행동 완주 |
| ③ 고령 부모와 가족 | 대신 확인·보호하고 싶은 자녀 | 고령자 모드(큰 글씨·쉬운 말·음성) + 가족 공유 리포트 |
| ④ AI 에이전트 | 타 AI 비서·심사용 크롤러가 검증 요청 | **Agent 인터페이스**: API·MCP·llms.txt |

## 3. 솔루션 = 데스크(전면) + 상황실(후면), 하나의 부서

### 전면 — 사기대응 데스크 (오늘 당장 쓸 수 있는 것)

랜딩 페이지가 곧 제품: 로그인 없음, 입력창 하나 + 샘플 시나리오 3버튼.

1. **판정**: 문자·대화·상황 설명 입력 → 위험 신호 형광 하이라이트 + 수법 DB 매칭 근거 카드
   + 확인 질문 → 판정(위험/주의/낮음). **정상 메시지는 정상이라고 말한다** — 겁주기 앱이 아니라
   보정된(calibrated) 판단 보조
2. **골든타임 오케스트레이션**: "이미 송금했어요" → 경과 타이머와 함께 행동 카드 순차 실행 —
   은행별 지급정지 요청 문구 자동 생성 → 112·1394 연결 스크립트 → 증거 보존 체크리스트.
   전부 공공 채널만 사용하므로 **기관 통합 없이 사용자 테스트 가능한 MVP** ("실사용 가능"
   표현은 템플릿 검수·보안·운영 기준 통과 후에만 사용)
3. **산출물**: 신고 준비 브리핑 PDF(신고서 초안+사건 타임라인+증거 체크리스트, 참고용·
   미제출 표시) + 가족 공유용 1페이지 요약

### 후면 — 상황실 (부서 스케일의 증명)

심사위원이 "상황실 보기"를 누르면: **방금 자신이 만든 사건이 라이브 피드에 떠 있다.**

- 6개 에이전트 협업 타임라인 (트리아지→분석가→케어→오케스트레이터→리포터→QA)
- 계좌·번호·URL 관계 그래프, 수법 트렌드 대시보드, 골든타임 도달률·처리 시간 지표
- 부서 서사: 사건 1건 = 케이스 파일 1개가 접수부터 보고서까지 전 주기 처리됨

### Agent-friendly 레이어 (Uniqueness의 쐐기)

- **공개 API + MCP 서버**: 다른 AI 비서가 "이 메시지 사기인지 검증해줘"를 호출 — 사기 검증을
  사람도 AI도 쓰는 인프라로. AI 심사(크롤러)에게는 기계가독 표면 제공
- llms.txt·구조화 JSON·시맨틱 마크업(ARIA) — 접근성과 agent-가독성을 한 번에
- 서사: 프론티어 AI 시대, 사기도 AI를 통해 온다 — 검증도 agent-to-agent로

### 신뢰 레이어 (금보원 만장일치 장치)

- **공개 안전성 리포트 페이지**: 합성 시나리오 오분류율, 프롬프트 인젝션 레드팀 결과를 우리가
  먼저 공개 — "AI 보안 비서를 스스로 검증까지 한 팀"은 우리뿐일 것
- 모든 판정에 근거 인용 강제, "판단 보조이며 최종 확인은 공식 채널" 고지, 쿨링오프 UX

## 5. 심사 데모 시나리오 (2분 풀코스, 30초 안에 1차 감탄)

- 0s: 랜딩 = 입력창 + "택배 스미싱 / 검찰 사칭 전화 / 자녀 사칭 카톡" 샘플 3버튼
- 10s: 샘플 클릭 → 위험 신호가 형광으로 켜지고 근거 카드가 붙음 (30초 wow 지점)
- 30s: "이미 송금했어요" → 골든타임 모드: 경과 타이머, 지급정지 문구·신고 스크립트 자동 생성
- 60s: 신고서+증거 패키지 PDF 다운로드
- 80s: 상황실 전환 → **내 사건이 라이브 피드에** → 에이전트 협업 타임라인·관계 그래프
- 110s: 안전성 리포트 + API/MCP 문서 (개발자·AI 심사용)
- 심사위원의 자유 입력 대비: 정상 문자 판별(낮음 판정), 적대 입력(가드레일 작동 표시)

## 9. 한계 고지 (과장 방지 — 서비스 화면과 기획서에 동일하게 명시)

1. 본 서비스는 **판단 보조 도구**이며 수사·법적 판정을 대체하지 않는다. 긴급 상황은 112 우선.
2. 데모는 **합성·공개 데이터 기반**이며 실제 금융기관 시스템과 연동되어 있지 않다.
3. **오분류 가능성이 존재**한다 — 오분류율을 안전성 리포트 페이지에 수치로 공개한다.
4. 신고문·지급정지 요청 문구는 **고정 템플릿 + 슬롯 채움** 방식으로 생성한다 (LLM 자유 생성
   금지 구간 — 환각으로 잘못된 법적 문구가 나가는 것을 구조적으로 차단).
5. 골든타임 관련 수치는 공식 출처가 확보된 것만 표기한다.
6. 포지셔닝: 은행 사기대응팀의 **대체가 아니라 증강**. 국민에게는 "지금까지 없던 부서를
   제공"하되, 기관에게는 "당신 부서의 야간·과부하 시간을 보완"하는 이중 메시지.

## 10. 본선 Q&A 예상 문답 (킬러 질문 선제 대응)

| 예상 질문 | 답변 골자 |
|---|---|
| "시티즌코난과 뭐가 다른가?" | 시티즌코난은 악성 앱 탐지·금융사 연동에 강하다(먼저 인정). 우리는 그것을 대체하지 않고, 피해 상태별 순서·전달 문구·완료 추적·신고서 묶음을 만드는 허브 — 행동 카드에서 시티즌코난을 직접 안내 |
| "오판정하면 책임은?" | 차단이 아닌 '정보+선택' 설계, 보정된 판정(정상은 정상), 오분류율 공개, 판단 보조 고지 |
| "수법 DB는 어디서?" | 금감원 보이스피싱지킴이·경찰청·KISA 공개 사례 (P단계에서 출처 목록 확정) |
| "LLM이 잘못된 신고 문구를 만들면?" | 신고·지급정지 문구는 템플릿+슬롯 방식, LLM 자유 생성 금지 구간 명시 |
| "은행은 자체 FDS가 있는데 왜 필요한가?" | FDS는 거래를 보고, 우리는 거래 전후의 **사람**을 본다. 콜센터 ~20분/건 디플렉션 |
| "누가 지속 운영하나?" | 화이트라벨(은행 콜센터 앞단)·지자체 보급·agent API — §7 성장 서사 |

## 11. 리스크 관리

- 예시 3번 경쟁 몰림 → "비서가 아니라 부서" + agent 인터페이스 + 안전성 공개로 차원 분리
- 오판정 → 보정된 판정(정상은 정상), 하네스 공개, 판단 보조 고지
- 프롬프트 인젝션 → 가드레일 + 레드팀 결과 공개 (약점을 무기로)
- URL 안정성 → 무상태 설계·모니터링·API 크레딧 버퍼 (M단계 게이트)
