# 교차 선정 기준 — 페인포인트 → 컨셉 (2026-07-25)

조사 결과가 나오기 **전에** 고정한 필터다. 결과를 보고 기준을 만들면 사후합리화가 되고,
그것이 1차 리서치(후보 21개 중 19개가 요강 예시 안)를 만든 앵커링 실패의 메커니즘이었다.

## 왜 "교차"인가

대회 설명문은 **"금융소비자 특성과 서비스 채널을 고려한 맞춤형 금융 AI 서비스"**다.
소비자가 없으면 R1(주제 적합성, 가중치 15)에서 죽는다. 반대로 기관 고통이 없으면
D6(양면 시스템)과 R6(시상 정합성)이 약해진다. **양쪽이 같은 지점에서 아픈 문제**만이
두 조건을 동시에 만족한다.

조사는 기관 쪽 4개(a1 금보원·금융위 / a2 은행권 / a3 증권 / a4 보험)와
소비자 쪽 3개(b1 민원·분쟁 / b2 실태조사 / b3 제도 사각지대)로 나눠 **독립적으로**
수행한다. 양쪽이 서로 모른 채 같은 지점을 가리키면 그것이 진짜 신호다
(1차 리서치에서 독립 검증자 2명이 수렴한 것이 유일하게 살아남은 근거였다).

## 게이트 (하나라도 FAIL이면 후보 탈락)

| 게이트 | 기준 | 근거 |
|---|---|---|
| **G-소비자** | 금융소비자가 주인공인가. 금융회사 내부 전용 도구는 탈락 | 요강 [설명] 문구 |
| **G-데이터** | 합성·공개 데이터만으로 v1 구현 가능한가 | 실금융데이터 사용 불가 |
| **G-체험** | 심사위원이 로그인 없이 30초 안에 가치를 체험할 수 있는가 | 루브릭 R4 |

> 2026-07-25 기록: 오케스트레이터가 제안한 규제 변경 추적기·책무구조도·제3자 리스크
> 3건은 **G-소비자에서 전부 탈락**했다. 기관 내부 도구였다. 이 게이트가 없었으면
> 다시 앵커링될 뻔했다.

## 채점 축 (각 0~3점, 합 24점)

| 축 | 0점 | 3점 |
|---|---|---|
| **F1 양면 통증** | 한쪽만 아픔 | 기관·소비자가 **같은 지점**에서 아프고, 양쪽 근거가 독립 조사에서 각각 나옴 |
| **F2 예시 밖** | 요강 예시 ①~⑦에 정면 해당 | 예시 어디에도 해당 없음 (인접해 보이면 **축이 다른 이유**를 한 문장으로 댈 수 있어야 함) |
| **F3 근거 강도** | 규모 미확보 또는 2차 보도만 | 1차 출처 URL + 기간·주체·정의가 명시된 수치 |
| **F4 기존 수단 공백** | 이미 제공하는 서비스가 있음 | 기존 제도·서비스가 어디까지 하는지 **문서로 확인**했고 그 다음이 남아 있음 |
| **F5 맞춤형·채널** | 모두에게 같은 화면 | 소비자 특성(연령·상황·역할)별로 **출력이 실제로 달라지고** 채널이 명시됨 |
| **F6 깊이 잠재** | T1~T4 (프롬프트 래퍼/RAG 챗봇/계산기/체크리스트) | D 신호 3개 이상이 자연스럽게 필요함 — 억지로 붙이는 게 아니라 **없으면 문제가 안 풀림** |
| **F7 6주 실현** | 실데이터·기관 협조 필수 | 공개 API 또는 합성 데이터로 v1 완주 가능 |
| **F8 시상 정합** | 어느 기관과도 연결 약함 | 특정 시상 기관의 공식 전략·소관 제도와 문서로 연결됨 |

## 판정선

- **19점 이상**: 컨셉 후보로 승격, 1차 출처 심층 검증 대상
- **14~18점**: 조건부 — 약한 축을 보강할 수 있으면 재평가
- **13점 이하**: 탈락

## 검증 단계에서 반드시 죽여볼 것

승격된 후보는 아래를 **반증 시도**로 확인한다. 1차 리서치에서 후보 21개 중 4개가
여기서 죽었고, M단계에서 계약 인용 6건 중 4건이 여기서 죽었다.

1. **기존 서비스가 이미 한다** — 공동개최사 자사 서비스 포함. 심사위원이 그 회사 사람이다
2. **부재 단정** — "~가 없다"가 실제로는 있는 경우
3. **수치 오귀속** — 업권·기간·정의가 다른 수치를 끌어옴
4. **정부 공식 프레임과 배치** — 예: 보이스피싱 "폭증"(정부는 감소+풍선효과)
5. **법적 성립 여부** — 우리가 제안하는 구조가 현행법상 가능한가
6. **AI 필요성** — AI를 빼도 같은 가치가 나오면 R1이 0점이다
