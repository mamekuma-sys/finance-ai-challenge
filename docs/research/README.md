# 주제 발굴 딥리서치

주최·후원사가 지금 실제로 풀고 싶어하는 문제를 찾아 sharp한 문제 인식을 뽑는 것이 목표.
심사 주체와 시상 구조에 맞춰 리서치 대상의 우선순위를 둔다.

## 리서치 대상 (우선순위순)

| 기관 | 역할 | 주목할 것 |
|---|---|---|
| 금융보안원 | **주최/주관** (최우수상) | 보도자료, 연구보고서, 이상거래·보이스피싱·AI 보안 관련 발간물 |
| 금융위원회 | 후원 (대상) | 정책 아젠다 — 포용금융, 소상공인 지원, 외국인 금융, AI 정책 |
| 하나은행 | 공동개최 (우수상) | 최근 AI 사업, 디지털 전략, 보도자료 |
| 신한은행 | 공동개최 (우수상) | 외국인 특화 서비스, AI 뱅킹 |
| 카카오뱅크 | 공동개최 (우수상) | 청년·포용금융, AI 서비스 |
| KB증권 | 공동개최 (우수상) | 투자 정보 서비스, AI 리서치 |
| 생명보험협회 | 공동개최 (우수상) | 보험사기, 보험 접근성 |

## 수집 항목 (기관별)

- 최근 1년 보도자료·공시·발표 중 AI/디지털 관련
- 공개적으로 언급된 현안·페인포인트
- 이미 출시된 관련 서비스 (→ 중복 회피, 빈틈 발견)
- 활용 가능한 공개 데이터·API
