# 주제 발굴 딥리서치

주최·후원사가 지금 실제로 풀고 싶어하는 문제를 찾아 sharp한 문제 인식을 뽑는 것이 목표.
심사 주체와 시상 구조에 맞춰 리서치 대상의 우선순위를 둔다.

## 컨셉 계보 (읽는 순서)

리서치는 **3라운드**를 거쳤다. 최종 산출물만 유효하고, 앞 라운드는 **"무엇을 왜 죽였는가"의
기록**으로 남는다 — 이것이 루브릭 R5 감점(기존 서비스 4개 층 미조사, −5)의 방어 근거다.

| 라운드 | 산출물 | 결과 |
|:-:|---|---|
| 1 | `01-sponsors/` · `02` · `03` · `04` · `05` · **`06-decision.md`** | 「골든타임」 선정 → **2026-07-26 폐기**(T4 신호·기존 수단 중복) |
| 2 | `07-pain/`(7건) · `08` · `09-verify/`(8건) · `10` · `11` · **`12-final-concept.md`** | 후보 C(고령 권한 이양) → **폐기**(부서 아님) |
| 3 | **`13-concept-brief.md`**(사망표·금지 레지스트리) · `14-org-map.md` · `15`~`18`(컨셉 5라운드) · **`19-verify-final3.md`** · **`20-concept-comparison.md`** | **「기록으로」 확정** |

**현행 컨셉 문서는 `docs/planning/31-solution-lock.md`**이며, 기획서·명세서는
`docs/planning/40`·`41`이다. 폐기 컨셉 문서는 `docs/archive/goldentime/`에 있다.
