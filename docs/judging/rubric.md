# AI 심사 역설계 루브릭 v1

> 전제: 본선 심사는 "내부 비공개 심사위원단 평가 100%, 주제 적합성·부적격 여부 등"이 공식 기준의
> 전부다. 수백 팀 제출물(기획서 PDF + 기능명세서 PDF + URL)을 사전 검토하려면 AI 스크리닝이
> 개입할 가능성이 높고, 상위권은 후원사 소속 전문가가 직접 본다. 따라서 이 루브릭은 두 층을
> 모두 통과하도록 설계한다:
> - **AI 판독층**: 구조·일관성·출처 표기·체크리스트를 기계적으로 평가 (LLM은 사실 검증을 못 하므로
>   내부 일관성과 근거 표기를 본다)
> - **전문가층**: 자기 기관 서비스·통계를 아는 사람이 본다 (잘못된 수치·"최초" 과장·자사 서비스
>   중복이면 그 자리에서 감점)

## 채점 차원 (각 0~10점, 가중 합산)

### R1. 주제 적합성 — 가중치 15

- **10**: AI가 가치 창출의 핵심 루프에 있고(제거하면 서비스가 성립 안 함), 해결하는 금융 현안이
  주최·후원사 공식 문서(보도자료·업무계획)로 입증되며, 금융소비자 특성(연령·언어·상황)과 서비스
  채널을 명시적으로 반영 — 대회 설명문("금융소비자 특성과 서비스 채널을 고려한 맞춤형")과 직결
- **5**: AI를 쓰지만 보조적이거나, 현안 연결이 일반론("금융사기가 심각하다")
- **0**: AI 없이 동일 가치 제공 가능, 또는 금융 현안이 아님

### R2. 문제 정의 — 가중치 20

- **10**: 한 문장 문제 정의 + **검증 통과한** 정량 근거(출처 링크, 기간·주체 정확) + 구체적 타깃
  페르소나 + "왜 지금인가" + 기존 서비스가 이 문제를 못 푸는 이유의 입증
- **5**: 문제는 명확하나 근거가 정성적이거나 출처가 약함
- **0**: 솔루션에서 역산한 문제, 근거 없음
- **감점 트리거**: 미검증 수치 인용(-2), "~가 없다" 부재 단정(-2), 타 업권·타사 수치 오귀속(-3),
  정부 공식 프레임과 배치되는 주장(-2, 예: 피해 "폭증" — 정부는 감소+풍선효과로 발표)

### R3. 솔루션 설계·AI 깊이 — 가중치 20

- **10**: 깊이 신호(D1 멀티에이전트 / D2 실시간·시뮬레이션 / D3 비정형 파이프라인 / D4 도메인
  계산 엔진 / D5 평가·안전 하네스 / D6 양면 시스템) **3개 이상** 실구현 + AI 출력의 근거 인용
  강제·가드레일 포함 (`docs/research/03-scoping-review.md` 기준)
- **5**: RAG/LLM 호출 중심이나 도메인 로직 일부 존재
- **0**: 탈락 신호(T1 프롬프트 래퍼 / T2 정적 RAG 챗봇 / T3 계산기+설명 / T4 체크리스트 생성기)
- **가점**: 금융 AI 안전성 검증 장치를 직접 만들어 보여줌(+1, 금보원 2026 전략 정합)

### R4. MVP 완성도·실현성 — 가중치 20

- **10**: URL 즉시 접속(로그인 장벽 없음 또는 데모 계정 원클릭), 첫 30초 안에 핵심 가치 체험,
  기능명세서 기재 기능이 전부 실제 작동, 심사 기간(9/7~9/11) 무중단 설계(모니터링·API 크레딧
  버퍼), 합성·공개 데이터임을 UI에 명시
- **5**: 작동하나 일부 기능 미완 또는 명세서와 불일치
- **0**: URL 불안정·명세와 다름·에러 노출
- 리서치·기획 단계에서는 "구현 계획의 구체성·현실성"으로 대체 평가

### R5. 독창성·차별성 — 가중치 10

- **10**: 기존 서비스 비교표(기관 자사 서비스 포함)로 공백을 입증, 심사위원 소속 기관이 이미
  하는 것과 중복 없음, 검증 다이제스트의 💀 전제 미사용
- **5**: 차별점 주장은 있으나 비교 대상 불완전
- **0**: 기존 서비스 재구현, 잘못된 "최초·유일" 주장

### R6. 기대효과·시상 정합성 — 가중치 10

- **10**: 수혜자 규모·효과를 검증된 수치로 정량화, 특정 시상 기관의 공식 전략·정책 과제와
  명시적 연결(문서 인용), 사회적 가치(포용·보호) 서사
- **5**: 방향은 맞으나 정량화 부족
- **0**: 막연한 기대효과("편리해진다")

### R7. 문서 품질·AI 판독성 — 가중치 5

- **10**: 데이콘 양식 섹션 완비, 핵심 주장이 표·다이어그램으로 구조화, 문단당 하나의 주장,
  용어 일관(기획서↔명세서↔서비스 화면 동일 용어), PDF 텍스트 추출 안전(이미지 속 글자에
  핵심 정보를 넣지 않음), 숫자마다 각주·출처
- **0**: 양식 무시, 벽글, 문서 간 용어·수치 불일치

## 채점 원칙 (드리프트 방지)

1. 앵커 기준으로만 채점한다. 이전 리포트를 보고 채점하지 않는다 (델타 비교는 채점 후에).
2. 모든 점수에 근거 인용(파일 경로 + 해당 구절)을 붙인다. 인용 못 하면 그 점수는 무효.
3. 냉정하게: **7점 = 제출 가능 하한선**. 근거가 애매하면 낮은 쪽.
4. 수치 인용은 `docs/research/04-verification-digest.md` 정정표와 기관별 `05-verification.md`
   판정을 통과한 것만 인정.
